# MyManabi

子どもの家庭学習を支援する AI 学習環境の設計と PoC。

単に正解を返すだけでなく、教科書に沿って学習を一度走り切れること、つまずきや判定への違和感をその場で示せること、AI が解けない問題を大人との会話へ渡せること、そして正答率だけでなく到達水準・安定性・つまずき方を記録できることを重視する。

> **状態**: 設計・PoC 段階。アプリのコードはまだ含まれていない。

## ドキュメント

- [コンセプト](docs/concept/README.md) — 目的・方針・前提・到達点・保留事項・リスク
- [仕様](docs/spec/README.md) — 学習フロー・理解度測定・教材管理・学習履歴・レポート・データ配置

## データの扱い（重要）

学習者の記録や手書き画像・音声などの個人情報、実教科書由来の教材コンテンツは、**本リポジトリには含めない**。これらは本リポジトリ外の DATA_DIR（例: `%APPDATA%/MyManabi`）に置く。リポジトリに含めるのは、データ形式を示す合成データ（将来追加する `examples/`）とスキーマのみ。詳細は [仕様 9. データ配置](docs/spec/README.md#9-データ配置) を参照。
